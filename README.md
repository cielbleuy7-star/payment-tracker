# 支払い管理

iPhoneのホーム画面に追加して使う、支払いの記録・履歴管理アプリです。
サーバーを使わず、データはすべて端末内（localStorage）に保存されます。

公開URL: https://cielbleuy7-star.github.io/payment-tracker/

## 機能

- **家計 / 個人の切り替え**：画面上部のトグルで「家計」「個人」を切り替えられます。履歴・集計・固定費はそれぞれ完全に独立して管理され、合算表示はされません
- **履歴**：日付・金額・カテゴリ・メモを記録し、一覧で確認・編集・削除できます
  - 月別・カテゴリ別にフィルタできます
  - 支払いごとに「建替払い中」ステータスを設定でき、あとから変更できます
  - 「建替払い中のみ」で抽出して確認できます
- **集計**：カテゴリ別の内訳（横棒グラフ）と、直近6ヶ月の推移（棒グラフ）を表示します
- **固定費**：サブスクや固定費を登録すると、支払日の7日前からアプリ内にリマインドバナーが表示されます（通知を許可すればブラウザ通知も届きます）
- **設定**：データをJSONファイルとして書き出し／読み込みできます（「家計」「個人」両方まとめて）。機種変更時はこれを使って新しい端末にデータを移行してください

## 使い方（iPhoneへの追加）

1. iPhoneのSafariで公開URLを開く
2. 共有ボタン（□に↑）をタップ
3. 「ホーム画面に追加」を選択

ホーム画面のアイコンから、全画面アプリとして起動できます。オフラインでも動作します。

## データについて

- 支払い履歴・固定費のデータは端末内のlocalStorageにのみ保存され、サーバーには送信されません
- 機種変更の際は「設定」タブの「バックアップを書き出す」で新しい端末にファイルを移し、「バックアップを読み込む」で復元してください（iCloud復元だけでは引き継がれない場合があります）
- iPhoneとPCなど複数端末間でのデータの自動同期は現時点では非対応です。手動でのバックアップ書き出し／読み込みで対応してください

## 技術構成

- 素のHTML / CSS / JavaScript（ビルド不要）
- グラフ描画: [Chart.js](https://www.chartjs.org/)
- PWA対応: `manifest.json` + `service-worker.js`（ホーム画面追加・オフライン動作）
- 公開: GitHub Pages

### ファイル構成

```
index.html         画面構造
style.css           スタイル（ライト/ダークモード対応）
app.js              アプリのロジック
manifest.json        PWA設定
service-worker.js    オフラインキャッシュ
icons/               ホーム画面アイコン
```

## 開発・動作確認

静的ファイルのみなので、ローカルで確認する場合は以下のようにHTTPサーバーを立てて開いてください（`file://` で直接開くとService Workerが動作しません）。

```sh
python3 -m http.server 8787
# http://localhost:8787/index.html を開く
```

コードを変更した際は、`service-worker.js` の `CACHE_NAME` の値を更新してください。既存端末にインストール済みのアプリへ変更を確実に反映させるためのキャッシュ更新の仕組みです。
